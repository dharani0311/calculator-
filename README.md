                    Simple Calculator 
________________________________________
1. Project Overview
This project is a simple web-based calculator designed using HTML for structure, CSS for styling, and JavaScript for functionality. It allows users to perform basic arithmetic operations with a clean and user-friendly interface.
________________________________________
2. HTML Documentation
Purpose
HTML is used to create the structure of the calculator. It defines the layout, display area, and buttons.
Structure Description
•	The document follows standard HTML structure.
•	A main container holds the calculator components.
•	An input field is used to display numbers and results.
•	Buttons are provided for digits, operators, clearing input, deleting input, and calculating results.
•	JavaScript is linked externally to handle calculator logic.
•	CSS is linked externally to apply styling.
Key Features
•	Uses semantic and simple elements.
•	Buttons trigger JavaScript functions using click events.
•	Display field is disabled to prevent direct user typing.
________________________________________
3. CSS Documentation
Purpose
CSS is used to design the appearance of the calculator and improve user experience.
Styling Description
•	Global styles remove default margins and apply a consistent font.
•	Flexbox is used to center the calculator on the screen.
•	A gradient background enhances visual appeal.
•	The calculator container has padding, rounded corners, and a fixed width.
•	The display area is styled for readability with proper font size, alignment, and color contrast.
•	Buttons are arranged using CSS Grid for equal spacing.
•	Hover effects provide visual feedback during interaction.
Design Benefits
•	Clean and modern layout.
•	Responsive alignment.
•	Improved readability and usability.
________________________________________
4. JavaScript Documentation
Purpose
JavaScript controls the behavior and logic of the calculator.
Functionality Description
•	Connects the display input field with the script.
•	Handles button clicks to update the display.
•	Clears all input when required.
•	Deletes the last entered character for correction.
•	Evaluates mathematical expressions and displays results.
•	Uses error handling to manage invalid inputs safely.
Error Handling
•	Prevents application crashes.
•	Displays an error message when calculation fails.
________________________________________
5. System Workflow
1.	User clicks calculator buttons.
2.	HTML captures button actions.
3.	JavaScript processes the input and updates the display.
4.	CSS ensures the interface remains visually organized and attractive.
5.	Result or error is shown on the display.
